## Quy ước

- ID là mã ổn định để tham chiếu qua các lần cập nhật; không tái sử dụng ID.
- Status: `[x] Complete` chỉ cho việc được xác minh bằng chứng; `[~] In progress` khi đã có code nhưng acceptance chưa đạt; `[ ] Planned` chưa triển khai/accept; `[!] Blocked` đang chờ gate hoặc quyết định nghiệp vụ/kỹ thuật.
- Dependencies dùng task ID hoặc Phase ID. Mọi sensitive workflow phụ thuộc `SEC-01` (Phase 2); không mở EMR, prescription/pharmacy hoặc billing trước gate này.
- Cột Evidence / blocker ghi bằng chứng hiện có hoặc điều kiện còn thiếu. Chưa có test/run evidence thì không tuyên bố test đã chạy.
